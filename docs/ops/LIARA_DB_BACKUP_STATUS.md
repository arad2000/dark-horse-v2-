# وضعیت backup دیتابیس لیارا — به‌روزرسانی پس از ارتقای پلن

## منبع و محدودهٔ شاهد

این یادداشت بر اساس **گزارش ناظر در همین جلسه** ثبت شده است، نه مشاهدهٔ مستقیم عامل از پنل، دریافت فایل یا اجرای restore. تاریخ درج‌شده برای backup در گزارش ناظر **2026-11-16** است؛ تاریخ ایجاد این سند را نباید تأیید مستقل زمان پنل دانست.

| مورد | وضعیت | شاهد و محدودیت |
|---|---|---|
| ارتقای پلن DB لیارا | **گزارش‌شده توسط ناظر** | ارتقا انجام شده؛ نام/مشخصات پلن جدید اعلام نشده است. این PR تنظیمات پلن را تغییر نمی‌دهد |
| backup دستی | **در پنل دیده‌شده توسط ناظر** | یک backup با تاریخ حدود `2026-11-16` و حجم حدود **85KB** گزارش شده؛ فایل دریافت یا اعتبارسنجی نشده است |
| پشتیبان‌گیری خودکار | **روزانه، طبق توضیح پنل به نقل از ناظر** | وجود این توضیح به‌تنهایی شاهد اجرای موفق روزانه نیست؛ آخرین اجرای موفق، retention، ساعت/منطقهٔ زمانی و PITR هنوز تأیید نشده‌اند |
| restore کامل backup واقعی لیارا روی کپی جدا | **NOT RUN / تأییدنشده** | در این کار انجام نشده است؛ سلامت فایل، پوشش داده و schema، بالا آمدن اپ پس از بازیابی و RPO/RTO واقعی هنوز اثبات نشده‌اند |

**حجم فایل کوچک است (حدود 85KB).** ممکن است دیتابیس کم‌داده باشد؛ حجم به‌تنهایی نه نشانهٔ خرابی است و نه شاهد کامل‌بودن یا قابلیت بازیابی backup. علت دقیق بدون بررسی فایل و تطبیق با DB مبدأ مشخص نیست.

## نسبت با گزارش‌های پیشین

- عبارت‌های «پلن پایه و بدون backup پنل» در [گزارش فاز ۳](PHASE3_LOAD_STEP_REPORT.md)، وضعیت گزارش‌شده **در زمان همان آزمون** بودند؛ گزارش جدید ناظر، وضعیت بعدی را به‌روز می‌کند و نتایج تاریخی بار را تغییر نمی‌دهد.
- در [گزارش فاز ۲](PHASE2_BACKUP_RESTORE_REPORT.md)، dump→restore محلی با دادهٔ مصنوعی PASS بود؛ آن آزمون **restore فایل واقعی لیارا نبود** و همچنان جای آن را نمی‌گیرد.
- پیش از ادعای قابلیت بازیابی تولید، با مجوز و دسترسی جدا باید backup واقعی در DB تازه و ایزولهٔ غیرتولیدی restore شود، schema/داده و سلامت اپ بررسی و مدت/نتیجه ثبت شود. هیچ restore روی DB زندهٔ کاربران مجاز یا اجراشده فرض نمی‌شود.

این PR فقط ثبت وضعیت ops است: بدون تغییر کد محصول، موتور، وزن‌ها، majors، سهمیه/خرید، تنظیمات DB یا deploy؛ بدون ادعای اثبات ظرفیت production و بدون اجرای تست restore جدید.
