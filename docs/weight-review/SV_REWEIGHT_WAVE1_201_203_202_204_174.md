- هیچ مقدار `strategy_weights` یا `value_weights` تغییر نکرده است.
- `majors_database_v2.json` فقط خوانده شده؛ در این PR تغییر داده نمی‌شود.
- هیچ `micro_motives.json`، `school_branches_v2.json`، engine، formula، test، expected fingerprint، Hybrid، cutover، UI یا env لیارا تغییر نمی‌کند.
- هیچ وزن از main یا همسایه کپی نشده و هیچ تلاشی برای کاهش اختلاف fingerprint یا signature انجام نشده است.
- فقط پنج شناسهٔ 201، 203، 202، 204 و 174 موضوع این موج‌اند؛ هیچ ID دیگری به دامنهٔ تصمیم افزوده نشده است.
- هیچ وزن پیشنهادی عددی نوشته نشده؛ بنابراین جدول 25S+15V پیشنهادی وجود ندارد.
- **Merge = خیر.** این سند فقط پیشنهاد تصمیم و برنامهٔ بازبینی را ثبت می‌کند؛ اعمال هر تغییر بعدی نیازمند دستور صریح ناظر در PR جداگانه است.
