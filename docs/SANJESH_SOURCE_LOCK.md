## اصل منبع

برای استخراج یا تکمیل داده، فقط سند منتشرشده از سوی **سازمان سنجش آموزش کشور** ملاک است:

1. دفترچه راهنمای انتخاب رشته آزمون سراسری سال 1405 (دفترچه شماره 2)، به تفکیک گروه آزمایشی در صورت ارائه فایل‌های تفکیکی.
2. پیوست‌ها و جداول رسمی بومی‌گزینی/شرایط و ضوابط همان سال.
3. جداول رسمی سهمیه‌های ایثارگران/رزمندگان و سایر سهمیه‌هایی که صریحاً در اسناد انتخاب رشته همان سال آمده باشند.
4. اطلاعیه‌ها و اصلاحیه‌های رسمی سنجش که بعد از انتشار دفترچه، وضعیت رشته‌محل/ظرفیت/شرایط را تغییر می‌دهند.

**ممنوع:** استفاده از سایت‌های مشاوره‌ای، کانال‌ها، وبلاگ‌ها یا داده‌های استخراج‌شده توسط اشخاص به‌عنوان منبع نهایی. این منابع فقط برای کشف نشانی سند رسمی قابل استفاده‌اند و وارد داده تولیدی نمی‌شوند.

## شناسه منبع رسمی

### درگاه اصلی

- سازمان سنجش آموزش کشور: https://www.sanjesh.org/
- مسیر موضوعی: «سراسری» → «انتخاب رشته آزمون سراسری سال 1405» → «دفترچه راهنمای انتخاب رشته/دفترچه شماره 2» و اصلاحیه‌های مربوط.

### سند اصلی

- **نام:** دفترچه راهنمای انتخاب رشته‌های تحصیلی آزمون سراسری سال 1405 (دفترچه شماره 2)
- **سال:** 1405
- **دامنه:** گروه‌های آزمایشی علوم ریاضی و فنی، علوم تجربی، علوم انسانی، هنر و زبان‌های خارجی؛ فایل/بخش متناظر گروه در نسخه رسمی سنجش ملاک است.
- **شناسه فایل رسمی:** در این محیط، فایل PDF مستقیم سنجش به‌دلیل محدودیت دسترسی وب‌سرویس سنجش قابل بازیابی مستقیم نیست؛ بنابراین هیچ URL آینه‌ای به‌عنوان شناسه منبع رسمی ثبت نشده است.
- **قاعده provenance:** تا زمان ثبت شناسه/URL مستقیم فایل رسمی، هیچ عدد یا نگاشتی که نیازمند مشاهده متن/جدول این PDF باشد استخراج و وارد JSON نمی‌شود.

### اسناد تکمیلی رسمی

- **پیوست‌های دفترچه انتخاب رشته 1405**: جداول و ضوابط تکمیلی مندرج در درگاه سنجش برای همان سال.
- **اصلاحیه‌های دفترچه 1405**: آخرین نسخه معتبر هر جدول/کدرشته‌محل/ظرفیت/شرط، در صورت انتشار رسمی.

## فیلدهای مجاز برای استخراج از منبع رسمی

فقط در صورتی که در PDF/پیوست رسمی همان سال صریحاً درج شده باشند:

| فیلد هدف | منبع | قاعده |
|---|---|---|
| `program_id` / کدرشته‌محل | جدول کدرشته‌محل | مقدار عیناً از منبع |
| عنوان رشته | جدول کدرشته‌محل | مقدار عیناً از منبع |
| دانشگاه/مؤسسه | جدول کدرشته‌محل | مقدار عیناً از منبع |
| شهر / استان محل ارائه | جدول کدرشته‌محل | مقدار عیناً از منبع |
| `course_type` / نوع دوره | جدول کدرشته‌محل | مقدار نرمال‌شده با حفظ مقدار مرجع |
| روش پذیرش | جدول کدرشته‌محل/بخش ضوابط | `exam` یا `record` فقط با مستند صریح |
| ظرفیت کل | جدول رسمی ظرفیت | فقط در صورت درج صریح؛ در غیر این صورت اضافه نشود |
| ظرفیت بومی | جدول رسمی ظرفیت | فقط در صورت درج صریح |
| ظرفیت آزاد | جدول رسمی ظرفیت | فقط در صورت درج صریح |
| `bomi_type` | بخش گزینش بومی/جدول کدرشته‌محل | فقط مقادیر صریح مثل استانی/قطبی/ناحیه‌ای/کشوری |
| استان‌های بومی | پیوست/جدول بومی‌گزینی | فقط نگاشت رسمی |
| قطب | پیوست/جدول بومی‌گزینی | فقط نگاشت رسمی |
| ناحیه | پیوست/جدول بومی‌گزینی | فقط نگاشت رسمی |
| سهمیه/حدنصاب خاص | بخش سهمیه‌ها و کدرشته‌محل | فقط مورد صریح و قابل ردیابی |

| سایر محدودیت‌های پذیرش | ضوابط رسمی | فقط متن مستند، بدون استنباط |

## فیلدهایی که از دفترچه Step 0 استخراج نمی‌شوند

- cutoffهای تاریخی یا پیش‌بینی‌شده؛ دفترچه انتخاب رشته منبع «حدنصاب آخرین قبولی» نیست.
- هرگونه نگاشت استان→قطب یا استان→ناحیه که در منبع رسمی صریحاً ارائه نشده باشد.
- ظرفیت بومی/آزاد در صورت نبود جدول رسمی.
- هر مقدار عددی که منبع رسمی برای آن وجود نداشته باشد.

## سیاست null و note

اگر فیلدی در منبع رسمی وجود نداشته باشد:

- مقدار آن `null`/غایب باقی می‌ماند.
- در مستندات و خروجی validator یک `note` صریح ثبت می‌شود.
- هیچ مقدار جغرافیایی، ظرفیت، حدنصاب یا سهمیه‌ای با حدس تکمیل نمی‌شود.

نمونه note:

> «در منبع رسمی سنجش برای این سال/فایل جدول نگاشت موردنیاز یافت نشد؛ مقدار عمداً null باقی مانده است.»
