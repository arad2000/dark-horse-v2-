### ۱-الف) کد کامل و بدون ویرایش `_active_branch_code_set` و `_compute_branch_m_score` (`dark_horse_engine_v2.py:171–216`)

```python
    def _active_branch_code_set(self, raw_codes: List[str]) -> set:
        codes = {str(c).strip().lower() for c in (raw_codes or []) if c and str(c).strip()}
        if self.motives_map:
            catalog = {str(k).strip().lower() for k in self.motives_map.keys()}
            filtered = codes & catalog
            if filtered:
                return filtered
        return codes

    # ──────────────────────────────────────────────────────────────
    # محاسبه M-Score برای شاخه‌ها (کالیبره‌شده بر اساس اندازه مخزن فعال هر شاخه)
    # ──────────────────────────────────────────────────────────────
    def _compute_branch_m_score(self, user_motives: List[str], branch_data: Dict) -> Tuple[float, List[Dict]]:
        if not user_motives:
            return 0.0, []

        raw_codes = branch_data.get("micro_motive_codes", [])
        if not raw_codes:
            return 0.0, []

        user_set = {str(m).strip().lower() for m in user_motives if m and str(m).strip()}
        branch_set = self._active_branch_code_set(raw_codes)
        matched = user_set & branch_set

        if not matched:
            return 0.0, []

        denom_limit = branch_data.get("m_score_denom_limit", 30)
        pool_sizes = [
            len(self._active_branch_code_set(b.get("micro_motive_codes", [])))
            for b in self.school_branches.values()
            if b.get("micro_motive_codes")
        ]
        mean_pool = (sum(pool_sizes) / len(pool_sizes)) if len(pool_sizes) > 1 else float(len(branch_set))
        pool_scale = (len(branch_set) / mean_pool) if mean_pool > 0 else 1.0
        denom = min(float(len(branch_set)), max(1.0, float(denom_limit) * pool_scale))
        score = len(matched) / denom

        matched_details = []
        for code in user_motives:
            code_lower = str(code).strip().lower()
            if code_lower in matched:
                desc = self.motives_map.get(code, "") or self.motives_map.get(code.upper(), "")
                matched_details.append({"code": code, "description": desc})

        return min(1.0, score), matched_details
```

### ۱-ب) ترکیب نهایی امتیاز شاخه و آستانه‌های حذف (سرور + کلاینت)

1. **فرمول نمرهٔ کل شاخه (`dark_horse_engine_v2.py:756–766`):**
   $$\text{Total}_b = 0.60 \times M_b + 0.20 \times V_b + 0.20 \times S_b, \qquad \text{UI fit\_score} = \text{round}(100 \times \text{Total}_b, 1)$$
2. **آستانهٔ حذف روی سرور (`dark_horse_engine_v2.py:783–795`):**
   - هر ۴ شاخه در آرایهٔ پاسخ برمی‌گردند، اما اگر $M_b < 0.15$ باشد پیام هشدار ثبت می‌شود و در حلقهٔ انتخاب `best_branch` (`if branch["avg_components"]["m_score"] >= 15`) آن شاخه **از نامزدیِ بهترین شاخه حذف می‌شود**.
3. **فیلتر سختِ حذف در رابط کاربری فرانت‌اند (`docs/app.js:3284–3295`):**
   - تابع `displayResults(data, 'branches')` کارت هر شاخه‌ای را که `fit_score < 30` **یا** **`m_score < 15`** داشته باشد **به‌طور کامل از صفحهٔ نتایج کاربر حذف می‌کند (`HIDDEN_BY_UI`)**!

### گزینه ۲ — نرمال‌سازی بر اساس بودجهٔ جرقه‌های کاربر / جرقه‌های در معرض دید *(گزینهٔ پیشنهادی ارجح: ۲-الف در سرور، یا ۲-ب سرتاسری)*

این گزینه دو زیرحالت دقیق دارد:

1. **زیرحالت ۲-الف (پیشنهاد ارجح برای فاز اجرایی فوری — فقط ۲ خط در سرور، بدون هیچ تغییر در API یا فرانت‌اند):**
   نرمال‌سازی یکسان همهٔ شاخه‌ها نسبت به تعداد کل جرقه‌های انتخابی کاربر با کف ایمن `15` و سقف `denom_limit = 30`:
   $$\text{denom} = \min\!\big(\text{denom\_limit},\; \max(15,\; |U|)\big), \qquad M_b = \min\!\left(1.0,\; \frac{|\text{matched}_b|}{\text{denom}}\right)$$

2. **زیرحالت ۲-ب (نرمال‌سازی دقیق بر اساس کارت‌های دیده‌شده در مسیرهای طی‌شده `exposed_motives`):**
