## Gap List

### P0 — نگاشت رسمی قطب/ناحیه

**وضعیت:** \`ghotbi=561\` ولی جدول نگاشت رسمی استان→قطب در داده وجود ندارد.

**اثر:** موتور نمی‌تواند بومی قطبی را دقیق اعمال کند.

**قاعده حاکم:** هیچ جدول قطب/ناحیه‌ای از خودمان ساخته نشود؛ خروجی باید «اعمال ناقص» + note داشته باشد تا منبع رسمی اضافه شود.

**محدودیت فعلی:** این gap مانع ساخت موتور پایه نیست، ولی مانع اعلام گزینش بومی قطعی برای این گروه است.

### P1 — ظرفیت

**وضعیت:** هیچ کلید ظرفیتی در 4,150 برنامه پیدا نشد.

**اثر:** ظرفیت کل، ظرفیت بومی، ظرفیت آزاد و سهمیه‌ای قابل اعمال نیست.

**قاعده حاکم:** ظرفیت ساختگی اضافه نشود؛ موتور فعلی فقط در صورت وجود داده معتبر ظرفیت را مصرف کند و در غیر این صورت note «تقسیم ظرفیت دفترچه در داده نیست» بدهد.

### P1 — provenance داده‌های \`cutoffs_bomi\`

**وضعیت:** فیلد موجود است، اما metadata آن را محاسبه‌شده از غیربومی معرفی می‌کند و در این dataset مدرک source رسمی برای آن ذخیره نشده است.

**اثر:** برای تولید خروجی قابل اعتماد، باید provenance آن در آینده به منبع رسمی قابل ردیابی شود.

**قاعده حاکم:** خروجی نباید این cutoffها را «cutoff رسمی سنجش» بنامد.

### P2 — مدل‌سازی کامل قیود دفترچه

**وضعیت:** فیلدهای تخصصی برخی شرایط خاص مانند مصاحبه/آزمون عملی و تعهد خدمت وجود دارند، اما هنوز بخشی از آن‌ها وارد موتور گزینش شانس نشده‌اند.

**اثر:** موتور پایه رتبه/cutoff را می‌تواند اجرا کند، ولی خروجی همه قیود پذیرش را مدل نمی‌کند.

## نتیجه Phase 1

### قفل‌شده و آماده برای Phase 2
- ساختار core program قابل استفاده است.
- نگاشت majorها کامل است.
- تفکیک با آزمون/سوابق کامل است.
- cutoffهای شش‌بعدی برای برنامه‌های با آزمون از نظر ساختار موجودند.
- minimum_gpa/minimum_traz برای سوابق موجودند.

### هنوز مجاز نیست
- اختراع نگاشت قطب/ناحیه.
- ساخت capacity جعلی.
- معرفی \`cutoffs_bomi\` محاسبه‌شده به‌عنوان cutoff رسمی.
- ادعای دقت 90%.
- تولید درصد شانس عددی.

## ابزار ممیزی

اسکریپت read-only زیر اضافه شده است:

\`scripts/validate_program2s_admission_contract.py\`

این اسکریپت:
1. ساختار core fields را بررسی می‌کند.
2. نگاشت majorها را با \`majors_database_v2.json\` می‌سنجد.
3. هر شش dimension cutoff را بررسی می‌کند.
4. پوشش minimum_gpa/minimum_traz را گزارش می‌دهد.
5. نبود ظرفیت و نبود mapping قطب/ناحیه را به‌عنوان gap گزارش می‌کند.
6. هیچ فایلی را تغییر نمی‌دهد.

اجرای آن در root repository:

\`python scripts/validate_program2s_admission_contract.py\`

این PR فقط **docs + validator** است. هیچ تغییر رفتاری در API یا UI ایجاد نمی‌کند.
