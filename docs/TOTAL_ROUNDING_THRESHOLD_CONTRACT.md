# قرارداد Total و آستانه‌ها — سیاست B (Draft)

**مبنای ممیزی:** deploy در `46456a687d6a3f96d5b9cebb69f86d3bd054f716`. سند پیش از افزودن تست نوشته شده؛ Merge فقط با دستور مستقل ناظر. انتخاب **B** چون رفتار جاری موتور/API/UI است و مرز محصول را با درصد گزارش‌شده یکی نگه می‌دارد؛ سیاست تازهٔ روان‌سنجی یا تغییر وزن نیست.

## مقیاس و گردکردن

Total خام در مقیاس ۰–۱ ساخته می‌شود: رشته `0.55*M + 0.30*V + 0.15*S`؛ شاخه `0.60*M + 0.20*V + 0.20*S`. تنها مقدار قرارداد نمایش/مقایسه، **`round(total * 100, 1)`** در مقیاس درصد است؛ از مؤلفه‌های درصدیِ ازقبل‌گردشده برای بازسازی Total استفاده نمی‌شود.

این همان `round` فعلی Python روی **float دودویی** است: نزدیک‌ترین مقدار با یک رقم اعشار؛ در تساوی دقیق، ties-to-even، نه half-away-from-zero و نه Decimal quantize. نمایش متنی می‌تواند صفر انتهایی را حذف کند (`30` و `30.0` یک مقدارند). مثال اعشاری نوشته‌شده لزوماً تساوی دقیق دودویی نیست؛ `round(30.05,1)=30.1` و `round(30.25,1)=30.2`. epsilon/تصحیح اعشاری تازه‌ای اضافه نمی‌شود.

## null و دامنهٔ قفل

در مسیرهای جاری، S ناقص/بی‌شاهد یا V ناقص/مرجع ناقص/بی‌شاهد، **قبل از ساخت Total** به `incomplete_assessments` می‌روند؛ null صفر/۰٫۵ نمی‌شود، ضرایب بازتوزیع نمی‌شوند و رکورد عددی رتبه‌بندی/ذخیره نمی‌شود. M در قرارداد جاری عددی است: صفر انتخاب معتبر خروجی صفر است، نه null؛ M=null خروجی معتبر این موتور نیست و برای آن فرمول تازه یا جانشین نمی‌سازیم. محافظ API نمرهٔ ناموجود/غیرمتناهی و V ناموجود را رد می‌کند (`main_v2.py:534–541`)؛ محافظ عمومی برای null تزریقی M/S تعریف نشده و این موج آن را اضافه نمی‌کند. S و V مستقل و دلایلشان محفوظ‌اند.

**نیاز به اصلاح اجرایی مشاهده نشد**: تست‌ها همین مسیر موجود را قفل می‌کنند؛ موتور، API و UI بدون تغییر می‌مانند. M رشته/شاخه، S/EQUAL/۲۵، V/کف۱۵/null، ضرایب Total، اعداد ۳۰/۴۰/۶۰/۸۰، وزن/JSON، fingerprint، Hybrid/cutover، UI جرقه و e_b خارج از تغییرند. گیت تاریخی V/canonical تضعیف نمی‌شود.
