## واقعیت دانه
- دفترچه: ظرفیت **به ازای کد رشته‌محل** (هزاران ردیف).
- program2s: بدون capacity و بدون کد سنجش؛ دانه درشت‌تر
  (مثلاً «پیام نور تهران» = ۱۱۰ رشته، نه به ازای هر مرکز/کد).

## فرمول سهمیه (قطع از دفترچه، بدون آمار شرکت‌کنندگان)
از ظرفیت کل C:
1. seats_25 = floor(C × 0.25)   ← ایثارگران ۲۵٪
2. seats_5  = floor(C × 0.05)   ← ایثارگران ۵٪
3. R = C − seats_25 − seats_5
4. free ≈ ۲۰٪ از R  (پرمتقاضی روزانه: ۴۰٪ از R)
5. بقیه = استخر بومی — تقسیم مناطق نیازمند آمار شرکت‌کنندگان → فقط note

رشته‌های پرمتقاضی روزانه (۴۰٪ آزاد):
مهندسی برق، مکانیک، کامپیوتر، عمران، معماری، صنایع + حقوق، روانشناسی، حسابداری
