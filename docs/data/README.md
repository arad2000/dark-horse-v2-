# ظرفیت و سهمیه سوابق ۱۴۰۴

## واقعیت داده
- دفترچه: ظرفیت **به ازای کد رشته‌محل** دارد (هزاران ردیف).
- program2s: بدون capacity و بدون کد سنجش؛ دانه درشت‌تر است
  (مثلاً «پیام نور تهران» = ۱۱۰ رشته، نه به ازای هر مرکز/کد).

## آنچه از دفترچه قطعی است (بدون آمار شرکت‌کنندگان)
از ظرفیت کل C:
1. seats_25 = floor(C*0.25)
2. seats_5  = floor(C*0.05)
3. R = C - seats_25 - seats_5
4. اگر بومی: free ≈ 20% از R (پرمتقاضی روزانه: 40% از R)
5. بقیه = استخر بومی — تقسیم مناطق نیازمند آمار شرکت‌کنندگان است → فقط note

## مسیر تکمیل کامل
1. استخراج تمام جداول PDF → sanjesh_record_capacity_full.json (کلید: sanjesh_code)
2. نگاشت به program2s با (دانشگاه نرمال + رشته + دوره) یا گسترش دانه به سطح کد
3. موتور: اگر capacity_total بود shares را حساب کند؛ وگرنه invent نکند
