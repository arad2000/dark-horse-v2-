- مجموعهٔ مرتبط: **۵۷ تست PASS**؛ snapshot کامل مبنا: **۴۸ تست PASS**؛ ۹ تست جدید.
- Fingerprint: **۲۰ تست + ۳ subtest PASS**؛ هیچ گیت یا baseline مرجع تغییر نکرد.
- Red/green: همان تست partial روی موتور مبنا، با عدد ۱ به‌جای null شکست می‌خورد و روی Draft موفق است.
