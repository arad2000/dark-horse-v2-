# P1.4 — ممیزی پرش بین‌خوشه‌ای مسیرهای جایگزین

## پروتکل و قاعدهٔ شمارش

ممیزی از همان متد تولیدی `_compute_alternative_paths` استفاده می‌کند: فاصلهٔ ترکیبی بر پایهٔ ۶۰٪ RMS ارزش‌ها و ۴۰٪ RMS راهبرد، با بردار ۳۰بعدی ارزش‌ها و ۱۲۵بعدی SJT؛ سپس سه فاصلهٔ کمینه به ترتیب تولیدی انتخاب می‌شوند. هیچ وزن یا فرمول امتیاز Total دخیل/تغییر داده نشده است.

«پرش بین‌خوشه‌ای» فقط وقتی شمرده شده که هم رشتهٔ مبدا و هم مسیر مقصد دارای cluster غیرخالی باشند و برچسب‌ها متفاوت باشند. اگر یکی از دو خوشه خالی باشد، مورد «نامشخص» است و به‌عنوان پرش شمرده نمی‌شود. هدف‌های ممیزی فقط رشته‌های فعال‌اند (`motive_driven != false`)؛ کاندیداها مطابق همان تابع تولیدی بررسی شده‌اند.

## تصمیم اصلاح

**در این PR هیچ مسیر به‌خاطر تفاوت خوشه حذف یا جابه‌جا نمی‌شود.** قاعدهٔ اصلاح فقط زمانی روشن است که مسیر خارج از کاتالوگ باشد، به رشتهٔ غیرفعال اشاره کند یا از سه فاصلهٔ کمینهٔ متد تولیدی نباشد. ممیزی فعلی مورد غیرفعال در top-3 پیدا نکرد و مسیرهای گزارش‌شده مطابق ترتیب فاصله‌اند. حذف عمومی همهٔ مسیرهای بین‌خوشه‌ای، ماهیت مسیر جایگزین غیرمنتظره را با یک فیلتر دسته‌بندی سلیقه‌ای محدود می‌کرد.

به‌عنوان اقدام بعدی، مسیرهای 1→104 و 18→105 برای بررسی کاربری/پایلوت علامت‌گذاری شده‌اند؛ تا زمانی که قاعده یا دادهٔ مستقل مبنی بر نامعتبر بودنشان وجود نداشته باشد، وزن S/V و الگوریتم فاصله تغییر نمی‌کند.
