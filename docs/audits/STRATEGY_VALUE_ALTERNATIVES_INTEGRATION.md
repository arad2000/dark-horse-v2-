# اتصال کنترل‌شدهٔ آلترناتیوهای راهبرد/ارزش

## وضعیت و دامنه

این نسخه جایگزین طرح ردشدهٔ PR #383 است و برای Draft PR تازه آماده می‌شود. جدول سه‌رشته‌ای از تغییرات اجرایی کنار گذاشته شد؛ فایل موتور بایت‌به‌بایت با مبنای main برابر است. این سند مجوز merge یا استقرار نیست. اسناد ممیزی و scaffold قبلی بخشی از PR اجرایی جدید نیستند.

## backend

`main_v2.py::discover_v2` پس از محاسبهٔ اصلی، enrichment را در thread اجرا می‌کند. ماژول مستقل روی کاتالوگ کامل engine و پاسخ‌های request کار می‌کند؛ نمره‌های S/V هر رشته در cache محلی همان فراخوانی بازاستفاده می‌شوند. هیچ cache بین کاربران، پاسخ مدل، فاصلهٔ دو رشته، فیلتر M یا Total در انتخاب آلترناتیو دخالت ندارد.

نسخهٔ کپی‌شدهٔ نتیجه، هم در سطح بالا و هم در individuality_fit دارای `strategy_value_alternatives` و `alternative_paths` جدید است؛ فهرست قدیمی حتی در حالت نتیجهٔ خالی بازنمی‌گردد. امتیازها، ترتیب و اعضای توصیهٔ اصلی تغییر نمی‌کنند. method پاسخ، منبع جدید آلترناتیو را اعلام می‌کند؛ توضیح فاصلهٔ قدیمی برای این خروجی باقی نمی‌ماند.

دادهٔ جدید از مسیر موجود ذخیرهٔ نتیجه عبور می‌کند؛ schema، auth، مالکیت، سهمیه، session و توابع پایگاه تغییر نکرده‌اند. تست زندهٔ پایگاه یا gateway انجام نشده است. branch-discovery و موتور شاخه‌ها تغییر نکرده‌اند.

## frontend

صفحهٔ رشته‌ها عنوان جدید، نام آلترناتیو، دلیل راهبردی/ارزشی/هر دو و نمرهٔ هر بخش را نشان می‌دهد. نام‌ها escape می‌شوند. unknown با متن نبود اطلاعات نمایش داده می‌شود؛ پایین‌تر از آستانه، ناسازگاری قطعی نامیده نمی‌شود. پیام نبود نتیجه با کمبود داده متفاوت است و پوشش ناقص اعلام می‌شود.

نمرهٔ نمایشی حداکثر دو رقم اعشار دارد؛ صلاحیت از عدد خام backend و پرچم qualifies می‌آید، نه گردکردن مرورگر. محدودیت وزن‌های تخت و اینکه درصد، احتمال موفقیت نیست، آشکار است.

نتایج قدیمی بدون method جدید به مسیر عددی fallback نمی‌کنند و پیام نیاز به محاسبهٔ تازه می‌گیرند. محاسبهٔ تازه خودکار، پاک‌کردن storage، بازنویسی سابقه یا عبور از سهمیه انجام نمی‌شود. فهرست مشاوره در صفحهٔ رشته‌ها نیز از items جدید می‌آید؛ تماس واقعی مدل انجام نشده است. نمایش قدیمی شاخه‌های مدرسه محفوظ است.

## بررسی محلی

- ۱۳ تست پایتون انتخاب و enrichment: منبع، نمره، آستانه، ترتیب، سقف، کمبود داده، عدم mutation و اتصال پیش از persistence.
- تست JS renderer: دلیل‌ها، نمره‌ها، unknown، خالی، legacy، escape، پوشش و جداسازی شاخه‌ها.
- همهٔ standalone JS tests؛ hash راهنمای مشترک برای تغییر مجاز نتیجه به‌روزرسانی شده و متن راهنما ثابت مانده است.
- بدون تست بصری روی گوشی، بدون اتصال سرویس زنده و بدون تأیید استقرار.

محدودیت باقی‌مانده: ردیف تخت طبق S فعلی می‌تواند نمرهٔ کامل بدهد؛ رفتار فرمول تغییر نکرده و هشدار آن در نمایش جدید موجود است. این پیاده‌سازی اعتبارسنجی علمی جدید برای وزن‌ها ادعا نمی‌کند.

## حذف طرح قبلی

با دستور ناظر، تغییر MAJOR_CONTENT_NEIGHBORS کنار گذاشته شد. فایل dark_horse_engine_v2.py عین main است؛ تست و سند طرح سه‌رشته‌ای در PR جدید وارد نمی‌شوند. محاسبهٔ قدیمی ممکن است در داخل موتور انجام شود، اما enrichment خروجی رشته‌ها را در هر دو سطح با نتایج S/V جایگزین می‌کند؛ صفحهٔ جدید نیز برای نتیجهٔ قدیمی به آن fallback نمی‌کند. موتور شاخه‌ها دست‌نخورده می‌ماند.
