## زنجیرهٔ منبع

1. `dark_horse_engine_v2.py::_precompute_alternative_paths` هنگام ساخت موتور، برای تمام رشته‌ها cache می‌سازد.
2. `_compute_alternative_paths` پیش از این از `value_weights` بردار ۳۰تایی Q1A…Q15B و از `strategy_weights` بردار ۱۲۵تایی می‌ساخت.
3. `_hybrid_profile_distance` با وزن ارزش ۰٫۶۰ و راهبرد ۰٫۴۰ فاصله می‌داد؛ کاندیداها با مقدار گرد‌شدهٔ سه‌رقمی `distance` مرتب و سه مورد نخست انتخاب می‌شدند. محدودیت محتوایی، جدول همسایهٔ صریح یا فیلتر موضوع رشته وجود نداشت.
4. `discover_individuality` همان فهرست را به `individuality_fit.alternative_paths` می‌افزاید؛ تابع همسایگی ورودی پاسخ کاربر ندارد.
5. `main_v2.py::discover_v2` فهرست را بدون بازتفسیر به recommendation منتقل می‌کند.
6. `docs/app.js` زیر عنوان «مسیرهای نزدیک و جایگزین» نام‌های `r.alternative_paths` را نمایش می‌دهد. `docs/data.js` منبع این فهرست نیست.

نتیجه: نه جدول ID خراب شده، نه رتبهٔ همان پاسخ کاربر منبع است. شباهت پروفایل ارزش/راهبرد، به‌اشتباه به‌عنوان همسایگی ماهیتی عرضه شده است. تغییر وزن‌ها می‌تواند فهرست را عوض کند، حتی وقتی موضوع و کار رشته‌ها هیچ تغییری نکرده‌اند. نام الگوریتم قدیمی `hybrid_rms_euclidean_125d_strategy` است؛ حذف کاربرد آن از این فهرست، تغییر Hybrid/cutover یا امتیازدهی نیست.

این جدول پیشنهاد محتوایی برای بازبینی ناظر است، نه اعتبارسنجی علمی کامل پروتکل. معیار مرحلهٔ ۷ `docs/DH-013.md` اشتراک Core Verb و Dominant Object است؛ از ماتریس کامل و تأییدشدهٔ ۲۳۰ رشته در این اصلاح استفاده نشده و ادعای وجود آن نمی‌شود. هیچ وزن یا کهن‌الگویی بازتولید نشده است.

### محدودیت پوشش و رفتار نبود نگاشت

- پوشش فعلی فقط سه مبدأ از ۲۳۰ رشته است. برای ۲۲۷ رشتهٔ دیگر `alternative_paths=[]` برمی‌گردد؛ فرانت‌اند موجود بخش خالی را نمایش نمی‌دهد. این تغییر رفتاری عمدی و قابل‌توجه باید پیش از merge توسط ناظر پذیرفته شود.
- رشتهٔ 215 فعلاً مقصد است و نگاشت خروجی مستقلی ندارد. تقارن کامل گراف ادعا نمی‌شود.
- هیچ fallback عددی یا تکمیل خودکار با پیشنهاد نامرتبط وجود ندارد؛ فهرست فلسفه عمداً دو مورد دارد. این cutoff امتیازی نیست؛ صرفاً نبود نگاشت محتوایی بررسی‌شده است.
- تطبیق ID و نام مبدأ/مقصد از اشارهٔ خاموش به موضوع غلط پس از تغییر کاتالوگ جلوگیری می‌کند؛ نبود یا عدم تطبیق مقصد، همان پیشنهاد را حذف می‌کند.
- هیچ distance ساختگی، درصد نزدیکی یا تضمین تناسب فردی تولید نمی‌شود. `matching_method=explicit_content_neighbors_v1` و شکل نام/شناسهٔ موردنیاز مصرف‌کنندگان حفظ می‌شود.
- مسیر شاخه‌های دبیرستان (`_compute_branch_alternative_paths`) عمداً دست‌نخورده است؛ این Draft ادعای اصلاح همسایگی آن‌ها ندارد.
