# قفل منبع رسمی سنجش — مسیر صرفاً سوابق تحصیلی ۱۴۰۴

## دامنه

این سند فقط مسیر **پذیرش صرفاً بر اساس سوابق تحصیلی سراسری سال ۱۴۰۴** را پوشش می‌دهد.
مسیر با آزمون در این PR وارد نمی‌شود.

- تغییر scoring/ranking فردیت: ممنوع و انجام نشده
- Hybrid / PostgreSQL cutover: ممنوع و انجام نشده
- درصد شانس عددی: ممنوع و انجام نشده
- کالیبراسیون آماری: خارج از دامنه
- `dark_horse_engine_v2.py` و JSONهای علمی فردیت: دست‌نخورده

## منبع مالک

- **عنوان:** دفترچه راهنمای ثبت‌نام و انتخاب رشته پذیرش صرفاً بر اساس سوابق تحصیلی سراسری سال ۱۴۰۴
- **سال:** ۱۴۰۴
- **مسیر:** پذیرش/انتخاب رشته صرفاً بر اساس سوابق تحصیلی سراسری
- **منبع مورد استفاده:** فایل مالک معرفی‌شده توسط ناظر
- **شناسه/هش فایل مالک:** `null` — فایل مالک در workspace فعلی materialize نشده است؛ هیچ شناسه ساختگی یا URL آینه‌ای به‌عنوان منبع رسمی ثبت نشده.
- **قاعده provenance:** مقادیر اجرایی این PR فقط مواردی را پیاده می‌کنند که ناظر برای این منبع و صفحات آن مشخص کرده است. موردی که متن/جدول رسمی آن در دسترس نباشد با `null`/note باقی می‌ماند.
